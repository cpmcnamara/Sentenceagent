# Pattern Analysis: Essays vs. Essay Maps

This document analyzes each generated essay against its corresponding essay map pattern, identifying gaps, deviations, and suggested improvements to the patterns.

---

| Section | Pattern Requirement | Essay Performance | Gap/Improvement |
|---------|---------------------|-------------------|-----------------|

| MECHANISM | "Here's how it works..." | ✓ Uses signal | Pattern works well |
| | 5-10 paragraphs (heaviest section) | ✓ 5 paragraphs | Pattern works—could be longer |
| | Personal admission "I don't consciously..." | ✓ Exact usage | Pattern works well |

| | Connect back to opening | ✓ Returns to "endures" question | Pattern works well |

### Pattern Improvements Needed

1. **QUESTION section**: Add explicit instruction: "The final sentence of this section should state the question directly, without hedging."

2. **FIRST_ATTEMPT signals**: Add variants: "The obvious interpretation is...", "At first glance...", "The standard reading is..."

3. **MECHANISM transition**: Add explicit instruction: "CRITICAL: End MECHANISM with a question that leads to IMPLICATIONS. Use: 'If this is true, what follows?' or 'What are the consequences of this mechanism?'"

4. **Section length flexibility**: Add note: "Section lengths are guidelines. A section can exceed its suggested length if the substance demands it, provided it doesn't bloat with filler."

3. **SYNTHESIS specificity**: Add instruction: "The synthesis should name a single unifying pattern AND identify at least one tension between categories. The pattern should not be obvious from the overview—it should emerge from the detailed analysis."

4. **Evidence density tracking**: Add note: "Track footnote/citation density. DETAILED_ANALYSIS should be evidence-heaviest. If a category lacks citations, flag for revision."

### Pattern Improvements Needed

1. **SIMPLEST_VERSION accessibility**: Add instruction: "The simplest version should be understandable by someone with no background. If you find yourself using jargon, you're not at the simplest version yet. Ask: could a smart 14-year-old follow this?"

2. **WORKED_EXAMPLE visual note**: Add: "Ideally this section includes visual examples—diagrams, screenshots, computed outputs. For text-only contexts, use: numbered steps, clear before/after comparisons, or structural diagrams in ASCII if necessary."

3. **UNDERLYING_MECHANISM minimum depth**: Add: "This section should introduce at least one concept that wasn't in SIMPLEST_VERSION. If you're just restating the simple version in more words, you haven't gone deep enough. Ask: what's underneath the surface?"

4. **SYNTHESIS open questions**: Add requirement: "The final paragraphs should include at least one open question—something the explanation doesn't resolve. Wolfram essays are honest about the limits of understanding. Never end with false certainty."

5. **Question-answer spine**: Add note: "The essay's skeleton should be visible as a chain of questions: 'How does X work?' → 'What's the mechanism?' → 'What's underneath that?' → 'What are the complications?' This is explicit, not hidden."

## Cross-Pattern Improvements

Based on analyzing all six essays against all six patterns, here are improvements that apply across patterns:

### 1. Transition Explicitness
All patterns should have a "transition_sentence_template" for each section that gives the exact phrasing to bridge to the next section. Not just "transition to X" but "Use this sentence: [template]".

### 2. Substance Verification
Each pattern should include a "substance_checklist" for heavy sections. Example: "Heavy sections must include at minimum: 2 concrete examples, 1 personal admission, 1 mechanism explanation."

### 3. Length Flexibility Notes
Patterns should distinguish between "minimum length for substance" and "maximum before bloat." Current length ranges don't capture this distinction.

### 4. Signal Phrase Variants
All patterns should have 3-5 variants for each signal phrase, not just one canonical version. Writers naturally vary phrasing.

### 5. Coherence Agent Integration
Patterns should explicitly reference coherence_agent checks at each section. Example: "Before moving to next section, run backward_connection and forward_momentum checks."

### 6. Grand Theme Service
Each section description should include: "How this section serves the grand theme." This prevents sections that are interesting but disconnected.
